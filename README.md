# CampusFind — College Campus Lost & Found Portal

## Features
- Responsive dashboard and statistics
- Demo lost, found, and reunited reports
- Search by item, location, description, category, or reporter
- Filter by status and category; sort reports
- Report an item with validation
- Item detail view and reporter contact details
- Mark an item as reunited
- Copy item details
- Saves reports in browser `localStorage`
- My reports view for reports submitted in this browser

## Important notes
- This is a front-end academic prototype. Data is stored only in the current browser on the current device.
- Contact information is visible in this demo. For a real campus deployment, use authentication, access controls, server-side validation, and a database.
